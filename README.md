# 🚀 SKILLs para CLAUDE

![Status](https://img.shields.io/badge/status-em%20desenvolvimento-green?style=for-the-badge)
![License](https://img.shields.io/badge/license-MIT-blue?style=for-the-badge)

> Este projeto reúne busca Skills para Claude projetadas para simplificar trabalhos de escrita juridica ou escrita criativa, trnasformando conhecimentos e instruções repetitivas em uma capacidade reutilizavel que produzir uma resposta consistente.

O projeto tem como objetivo:

- Criar um processo de tarefas com mobilização de conhecimentos e recursos em ordem certa para obter a melhor resposta
- Reduzir o tempo gasto e consumo de tokens em tarefa de escrita complexa
- Estabelecer um formato de resposta mais previsivel e compatível com o esperado pelo usuário

## 🗂️ Catalogo 

    SKILL	                            OBJETIVO
📝 skill-advogado   	    Criar e melhorar petições judiciais
🤖 skill-poema      	    Criar e avaliar poemas
🔎 skill-tradutor	        Traduzir textos de ingles para ptbr
🐍 skill-flet	            Criar interfaces em Flet 
🏗️ skill-ebook          	 Criar ebooks
📊 skill-assessor+juridico	Analisar processos judiciais
📚 skill-streamlit      	Criar interefaces em Streamlit

## 🚀 Instalação

Clone o repositório:

git clone https://github.com/higo-ricardo/SKILL

Depois escolha a skill desejada na pasta SKILL e vá para o Claude.ai.
 
No menu lateral clique em PERSONALIZAR → HABILIDADE → ADICIONAR

Depois clique no botão SALVARe pronto.
