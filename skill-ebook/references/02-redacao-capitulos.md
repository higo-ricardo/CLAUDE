# 02 — Redação de Capítulos

**Agente**: AUTOR  
**Estágio**: M4

---

## Objetivo
Produzir capítulos de alta qualidade com estrutura sólida, voz consistente
e engajamento do leitor do início ao fim.

---

## Estrutura Padrão de Capítulo

### Não-ficção / Didático
```
1. GANCHO (1-2 parágrafos)
   └─ Pergunta provocadora, dado surpreendente, história curta ou promessa

2. INTRODUÇÃO DO CAPÍTULO (1 parágrafo)
   └─ O que o leitor aprenderá e por que importa

3. DESENVOLVIMENTO (corpo principal)
   ├─ Seção 1: conceito / argumento principal
   ├─ Seção 2: aprofundamento / evidências / exemplos
   ├─ Seção 3: aplicação prática / exercício / caso real
   └─ (repetir conforme necessário)

4. SÍNTESE (1 parágrafo)
   └─ Resumo dos pontos-chave em linguagem direta

5. TRANSIÇÃO (1-2 frases)
   └─ Conecta com o próximo capítulo, desperta curiosidade
```

### Ficção
```
1. CENA DE ABERTURA
   └─ In medias res preferencialmente; estabelece tom e personagem

2. DESENVOLVIMENTO DA CENA
   ├─ Ação / diálogo / descrição (proporção 40/40/20)
   ├─ Conflito ou tensão escalando
   └─ Revelação ou virada

3. CLIFFHANGER / FECHAMENTO
   └─ Gera urgência para o próximo capítulo
```

---

## Tree of Thought Aplicado à Redação

Para cada capítulo, gere 3 abordagens antes de escrever:

```
Caminho A — Abordagem Narrativa
  └─ Contar uma história real ou fictícia que ilustre o conceito

Caminho B — Abordagem Técnica
  └─ Explanação direta, estruturada, com dados e exemplos objetivos

Caminho C — Abordagem Socrática
  └─ Conduzir o leitor por perguntas que o fazem chegar à conclusão sozinho
```

Avalie cada caminho pelo critério do projeto (tom + público + gênero) e
escreva usando a abordagem mais adequada — ou uma combinação.

---

## Técnicas de Engajamento

### Para não-ficção:
- **Regra PAS** (Problema → Agitação → Solução) nas introduções
- **Microstories** — anedotas de 3-5 frases para ilustrar conceitos abstratos
- **Boxes de destaque** — dicas, alertas, exemplos em destaque
- **Perguntas retóricas** — no máximo 2 por capítulo
- **Listas com contexto** — nunca bullet points soltos; sempre com frase introdutória

### Para ficção:
- **Mostrar, não dizer** — ação e detalhe sensorial > descrição direta
- **Diálogo com subtexto** — o que o personagem NÃO diz é tão importante
- **Ritmo variado** — alternar frases longas (descrição) e curtas (ação)
- **POV consistente** — nunca mudar ponto de vista dentro da cena

## Checklist do AUTOR antes de entregar

- [ ] Gancho presente e eficaz?
- [ ] Tom e voz consistentes com o Documento de Projeto?
- [ ] Nível de linguagem adequado ao público?
- [ ] Todos os conceitos exemplificados?
- [ ] Transição com o capítulo anterior e próximo?
- [ ] Ausência de informações falsas ou não verificáveis?
- [ ] Tamanho adequado ao escopo do projeto?

## Funcionalidades Extras

### Gerador de Ganchos (ToT)
Para qualquer capítulo, gerar 5 opções de gancho:
1. Estatística surpreendente
2. Pergunta provocadora
3. Cena/história curta
4. Citação poderosa (verificada)
5. Afirmação contraintuitiva

### Modo Fantasma (Ghostwriting)
Se o usuário fornecer notas, transcrições de áudio (texto), posts ou rascunhos,
o AUTOR reescreve mantendo a voz original detectada no material de referência.

### Expansão de Tópico
Dado um tópico-frase (ex: "A importância do sono para a produtividade"),
expandir em capítulo completo com pesquisa integrada.

### Compressão de Capítulo
Dado um capítulo longo, comprimir mantendo 100% das ideias-chave,
eliminando redundâncias e exemplos fracos. Target: reduzir 30-40% sem perda.
