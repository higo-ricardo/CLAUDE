# Glossário CNJ — Decodificação de Números e Siglas

## Estrutura do Número CNJ

```
NNNNNNN - DD . AAAA . J . TT . OOOO
│          │    │      │   │    │
│          │    │      │   │    └── Órgão de origem (comarca, subseção)
│          │    │      │   └─────── Tribunal / Ramo (ver tabela abaixo)
│          │    │      └─────────── Dígito verificador do ramo
│          │    └────────────────── Ano de distribuição
│          └─────────────────────── Dígitos verificadores
└────────────────────────────────── Número sequencial (7 dígitos)
```
